# Contributing

Thank you for considering improvements to this frontend demo.

At this stage the project owner has not selected an open-source license. Please open an issue or contact the owner before contributing substantial code. Once a license is chosen, contributions may be accepted through pull requests.

Potential improvements include accessibility, responsive refinements, modular JavaScript, and automated cart/pricing tests.

Please do not submit personal information, real customer testimonials, copyrighted brand assets, or live payment credentials.
